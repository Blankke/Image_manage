# P3 实施计划：高置信自动几何与忠实恢复主链

## 1. 目标与冻结基线

P3 的目标是让“自动接受”第一次具备可审计的高置信语义，并建立从原始像素到忠实恢复结果的单一权威主链。几何质量优先于覆盖率；任何证据不足、目标多义、层级不确定或超出首版范围的输入都返回 `rejected`。

## 2. P3 主链与权威边界

正式主链固定为：

1. 只读加载原图并应用 EXIF 方向。
2. 按相机 profile、用户标定或通过安全门的轻量估计生成镜头逆映射；无可靠证据时保持恒等映射。
3. QuadLocator 输出 content/outer 角点热图、content mask、boundary、presence、类别及原始诊断量。
4. 统一角点解码器输出粗四角和多峰歧义诊断。
5. 原分辨率窄带精修，接受门失败时回滚粗四角。
6. 正确性校准器把可审计特征映射为 `P(strict_correct)`，再按风险阈值决定 accepted/rejected。
7. 将方向、径向畸变、透视和可选 dense dewarp 合成为一个输出到原图的逆映射。
8. 对原始像素执行一次 `remap`。
9. artifact router 选择 clean bypass、Demoire 或 Reflection；一次只允许一个强专项模型。
10. 依次执行 Fidelity、参数化 Photometric 和可选保守 SR。
11. 输出 provenance mask、参数、拒绝理由、模型版本和评估诊断。

`src/screenrestore/geometry` 是解码、精修、映射合成和接受决策的唯一运行时实现。训练、Torch 验证、ONNX、overlay 与 benchmark 必须复用同一解码规范和版本号。

## 3. 几何协议 G0–G2

### G0：统一解码和高置信接受

- 解码顺序：每角全局峰值 → 半径 NMS → 第二峰 → 主峰局部 5×5/7×7 sigmoid soft-argmax。
- 不再使用全图 softmax 坐标回归，也不使用固定阈值后的整图质心。
- 每角输出 peak1、peak2、差值、比值、峰间距离、归一化熵、局部 sharpness 和坐标。
- decoder spec 写入 checkpoint、ONNX sidecar、运行报告和 overlay。
- `strict_correct` 固定为：NCE ≤ 0.01、IoU ≥ 0.93、目标类别与 content 层级均正确。
- 校准特征只使用预测时可得量：presence/class/layer、四角多峰、mask/boundary、精修支持、几何形状和异常统计。
- 校准器为 JSON 可审计 logistic 模型，保存特征顺序、标准化参数、系数、截距、训练 manifest hash 和阈值。
- threshold 只由 validation/calibration 确定；test 仅冻结评估。

### G1：边界监督

- 由 content quad 在 head 分辨率生成有符号距离，再生成 1–3 px 高斯窄带目标。
- 损失为 class-balanced focal/BCE + Dice。
- 记录 boundary PR-AUC、最佳 F1、最佳阈值和 F1@0.5。
- B1 从 B0 warm start，只运行短阶段以验证监督是否开始学习。

### G2：尾部几何与困难样本

- 角点损失使用归一化 Smooth L1/Huber。
- 对每批正样本增加 CVaR 尾部项。
- 增加多峰歧义、mask/quad 一致性和 boundary/quad 一致性损失。
- hard taxonomy：nested-layer、partial/out-of-frame、multi-target、weak-edge、reflection、blur、extreme-perspective、none/non-planar。
- sampler 权重由 source、group、taxonomy 和 difficulty 共同决定，不允许 test 样本参与。
- B2 只做代码评估；B3 短训练验证损失有效；B4 只做运行时闭环评估；B5 才是唯一 FULL 几何训练。
- B6 仅在确认存在量化地板时启用，优先增加 subpixel offset head；不默认扩大 width multiplier。

## 4. 精修诊断与回滚

每条边记录残差 median/P95、连续覆盖率、梯度法向对齐、支持率和位移；整体记录面积漂移、长宽比漂移、mask/quad IoU 与 boundary 支持。

接受门要求：

- 四边均有连续证据；
- 位移不超过窄带限位；
- 面积和画幅漂移受限；
- mask/boundary 与精修后四边形一致；
- 几何合法且无自交。

输出状态为 `improved`、`neutral`、`worsened` 或 `rolled_back`。任何门失败都保留粗四角并记录原因。

## 5. 评估与 release gate

每次 geometry evaluate 生成：

- `evaluation.json`：逐样本冻结预测与严格正确性；
- `slices.json`：类别、来源、设备、taxonomy、难度和 in/out-of-scope 切片；
- `release-gate.json`：dev/release 指标与 PASS/FAIL；
- `risk-coverage.json`：风险-覆盖、precision-coverage、校准曲线、ECE、Brier 和阈值。

统计要求：

- 接受错误率给出精确二项 95% Clopper–Pearson 区间；
- 样本数按独立 `group_id` 统计；
- 零失败时约需 299 个独立 accepted groups 才能把 95% 错误率上界压到 1%；
- test 在阈值、校准器和 checkpoint 全部冻结后才运行。

开发门：NCE P95 ≤ 0.03、IoU P05 ≥ 0.85、accepted precision ≥ 0.95、in-scope coverage ≥ 0.50。

发布门：accepted precision ≥ 0.99、coverage ≥ 0.90、wrong-layer < 0.005、NCE P95 ≤ 0.01、IoU median ≥ 0.97、IoU P05 ≥ 0.93，且独立 group 数满足统计要求。

## 6. 单次几何采样与弯曲建模

### D1 径向畸变

- 模型参数为 k1、k2 与光心偏移。
- 来源优先级：相机 profile → 用户标定 → 通过身份/范围/单调/双射/直线安全门的估计 → identity。
- P3 中标记为 experimental，不因缺少 profile 强制校正。

### D2 轻度 dense dewarp

- 预测 17×17 或 33×33 低分辨率逆位移网格。
- 合成覆盖 TPS、mesh、curl、bend、lift 和轻度 sinusoid。
- 损失包含重建、bending、正 Jacobian、直线和 identity。
- P3 只完成生成器、模型、数值指标以及 ONNX/MPS smoke，不声称真实弯曲文档能力。

### 映射合成

方向、径向、homography 与 dense grid 均采用“输出像素查原始输入像素”的逆映射语义。合成后只调用一次 OpenCV remap。恒等映射、已知 homography、径向往返、正 Jacobian 和单次采样退化均需数值测试。

## 7. 忠实恢复链

### FidelityNet-v2

- 1–3M 参数、三尺度轻量 NAF 风格 encoder-decoder、skip、RGB residual 与 alpha/budget gate。
- 只学习 resize/noise/defocus/motion/JPEG/ringing。
- 合成 photometric nuisance 同时施加到 input 和 target，防止网络偷偷改曝光、白平衡和色调。
- clean identity 是硬门；失败则模型不得进入自动 Archive 路径。

### PhotometricNet

- 只预测 EV、RGB gains、3×3 residual CCM、每通道单调曲线和低频 log-gain grid。
- 参数由确定性可微变换应用；损失报告 RGB/线性 RGB、SSIM、edge、ΔE00、identity 和参数范围。

### DemoireNet 与 ReflectionNet

- Demoire 使用多尺度空间-频率结构，无 GAN/扩散；记录周期能量下降与 clean texture 保留。
- Reflection 输出透射估计、reflection mask 和 unresolved mask；改动必须局限于 mask，强饱和区域保持 unresolved。
- 两者只在 router 选择后运行，且同一次流程最多启用一个强专项。
- 未取得明确许可和真实 paired manifest 时只做 synthetic smoke，真实能力报告为 BLOCKED。

### Super-resolution 与 router

- 保留 P1 SR，先比较 bicubic、P1 和 P3 主链；只有条件门满足才允许重训。
- router 为多标签 artifact + severity 模型；clean 走 bypass，单一强 artifact 走对应 specialist，多个强 artifact 进入 review/reject 路径。

## 8. 数据、许可和磁盘预算

当前数据根目录约 23 GiB，硬上限 30 GiB，磁盘可用约 53 GiB。P3 不缓存在线 augmentation，不自动下载大型外部数据；任何下载前必须先打印预计下载量、解压量、保留量和最终总量。

恢复清单统一记录：reference_type、subject_id、group_id、capture_session、alignment、artifact labels/severity、degradation trace/parameters/masks、photo/lens/grid/device、source、license 和 redistribution restriction。subject/group/session 任一维度都不得跨 train/validation/test。

SmartDoc、MIDV-500、MIDV-Holo、DIV2K 和现有私有标注继续按原路径只读使用。FHDMi、真实 reflection paired data 和真实 dewarp 数据只有在许可、磁盘与清单均明确后才可进入正式训练。

## 9. 预算、元数据和统一入口

预算：

- `SMOKE`：1 epoch、极少样本、CPU/MPS/ONNX 合约验证；
- `ABLATION`：短阶段，只验证单一改动是否改善指定切片；
- `FULL`：唯一正式训练预算，由用户手动启动。

每个 run 写入 wall time、样本数、step、device、峰值内存、参数量、seed、git commit、manifest SHA-256、初始化 checkpoint、decoder version、命令参数和产物 hash。输出目录存在时硬失败，防止覆盖。

统一入口 `scripts/train_p3.sh` 提供：`preflight`、`smoke`、`geometry-b0` 到 `geometry-b6`、`dewarp`、`fidelity`、`photometric`、`demoire`、`reflection`、`superres`、`router`、`evaluate`、`report`。正式阶段要求 MPS 可用并硬失败；preflight/smoke 可使用 CPU。
