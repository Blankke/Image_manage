# ScreenRestore 开发记录

本文档记录里程碑、关键决策、验证命令和结果。它不是完成度宣传；实验性或未完成能力会明确标注。

## 实施计划

1. Milestone 1：工程骨架、图像加载、主窗口、缩放/平移画布、颜色转换、基础测试和 CI。
2. Milestone 2：自动四边形检测、手动四角编辑、透视与比例控制、几何测试。
3. Milestone 3：非破坏流水线、节点缓存、撤销/重做、白平衡、曝光、CLAHE、降噪和锐化。
4. Milestone 4：单图条带校正、传统去摩尔纹、热度图、频谱和预设。
5. Milestone 5：项目文件、全分辨率导出、后台任务、取消、日志、CLI 和 PyInstaller。
6. Milestone 6：外部程序后端、模型清单、分块融合、插件设置和文档收尾。

## 关键设计决策

- 内部图像统一为 RGB `uint8`；算法内部需要时转为 `[0, 1] float32`。
- 原图只读，流水线通过参数摘要识别节点缓存；参数变更只淘汰当前及下游节点。
- 预览代理最长边默认 1600 像素，导出始终从原始分辨率重新处理。
- 几何算子固定在流水线前部，输出缩放固定在末尾；其余算子允许重排。
- 首版所有算法为可解释 CPU 实现；模型与外部二进制仅通过可选后端接入。
- 第三方实现优先核查公开许可证；已移植代码必须在源码头、参考清单和第三方声明中
  记录原文件与修改。权利人针对当前项目的额外授权与公开许可证分开记录。

### 两个真实场景验证（第一轮）

- `电影屏幕测试.jpg`：原始轮廓检测因屏幕右边界贴住照片边缘而失败。增加受 Canny 支持约束的行列亮度跃迁回退后，得到四角 `[[23,261],[1275,261],[1275,838],[23,838]]`，置信度 0.68，输出 1252×577。画面裁切正确，影院低强度预设保留电影暗部；原图横跨人物面部的强宽条带仍有残留。
- `纸质海报测试.jpg`：自动四角为 `[[371,547],[903,533],[960,1385],[173,1333]]`，置信度约 0.529，输出 841×911。中央白色画作被正确分离并拉正。首次文档预设令 Laplacian 方差升至几何基线约 3.4 倍，视觉上过度强化纸张纹理与反光；据此将条带、CLAHE、照明和锐化下调为中等强度并重新验证。
- 回归：新增“屏幕被图像边缘裁切”的合成检测测试；脚本 `scripts/validate_samples.py` 可重新生成 `validation_outputs/` 中的几何基线、完整结果和有限 JSON 指标。
- 最终验证：Ruff 通过，pytest 35 项全部通过。

### 2026-08-01：真实样例第二轮与参考实现迁移

- 纸质海报旧 AUTO 比例由投影对边估成约 0.923，导致明显横向拉伸。加入基于消失
  点正交约束的弱相机标定后，估计物理比例约 0.699，并吸附到 A 系列 0.707；最终
  输出由 841×911 改为 736×1041。合成针孔相机回归测试同时覆盖该推导。
- 影院贴边候选不再强制轴对齐。沿初始边法线采样 Sobel 梯度、加权直线和迭代 MAD
  后，真实样例四角由 `[[23,261],[1275,261],[1275,838],[23,838]]` 细化为约
  `[[32,258],[1254,264],[1269,834],[15,841]]`，输出为 1254×583。
- 增加影院宽光幕模型：低分位黑位估计加性灰雾，只压制正向抬升并有限幅求逆。
  与梯度 DCT 折中处理合用后，该样例逐行黑位非均匀度从 0.029887 降到
  0.022212（约 25.7%），黑位无裁切；Laplacian 方差由 0.001730 提升到
  0.004048，高光裁切约 0.076%。覆盖人物面部的
  信息无法从单帧真实重建，仍保留可见残差。
- 移植 `fast-reflection-removal` 的梯度/DCT Poisson 核心并修复重复求解；实拍影院
  上高强度会损失真实低对比纹理。经 0.15、0.25、0.35、0.55、0.72、0.75 与满
  强度目视对比，影院预设采用 0.72 折中值并保留实验性标签；其他预设默认关闭。
- 移植 NAFNet 与 Real-ESRGAN 紧凑推理结构，增加官方权重 SHA-256 安装脚本、CPU
  tile 推理、模型流水线算子和三个清单示例。权重/二进制位于 Git 忽略目录，核心
  安装与 PyInstaller 仍排除 PyTorch。
- 实测结论：NAFNet GoPro width32 对影院样例自然但改善温和；Real-ESRGAN
  general-x4v3 对头发和纸质插画线条提升明显，但会产生绘画感/统计生成细节，因此
  两者均默认关闭，不作为“真实原始帧”。
- 纸质经典结果：Laplacian 方差由 0.002680 提升到 0.005607；逐行周期能量由
  0.00019787 降到 0.00011662（约 41%）；高光裁切约 0.0051%。
- 验证：`python -m ruff check src tests scripts` 通过；
  `QT_QPA_PLATFORM=offscreen python -m pytest -q` 为 44 项全部通过；真实样例脚本
  重新生成 `validation_outputs/diagnostics.json` 与经典/模型候选。
